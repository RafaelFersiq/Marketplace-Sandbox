## Processo para Criação de Novos ADRs

1. Copie o arquivo [template.md](file:///home/rafael-siqueira/Estudos/Projetos/Marketplace-Sandbox/docs/adr/template.md) para um novo arquivo nomeado como `NNNN-titulo-com-hifens.md`.
2. Preencha as informações detalhando o contexto, direcionadores, prós/contras das opções e consequências.
3. Abra um PR para revisão técnica.
4. Após a aprovação, atualize o índice acima.
